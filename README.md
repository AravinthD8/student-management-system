# Student Management System
A Spring Boot REST API application for managing students, courses, and student operations.
## Technologies Used
Java
Spring Boot
Spring Data JPA
Hibernate
MySQL
Spring Security
Maven
## Project Structure
Controller Layer
Service Layer
Repository Layer
Entity Layer
## Features
Student management
Search students by name
Search students by course
Student profile management
Course search and enrollment
Student authentication
Admin authentication
## Authentication
### Admin
Admin users can authenticate using their credentials.
### Student
Students can be validated using:
Student Code
Date of Birth
## How to Run
Clone the repository.
Configure the database in application.properties.
Run the application using Maven.

```bash
mvn clean install
mvn spring-boot:run

## API Testing
APIs can be tested using Postman.
